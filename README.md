## Overview

Propad is a Solana pad built around three ideas: equal footing at the opening bell, original names only, and swap revenue that is recycled into repurchases and permanent supply reduction. The site at [propad.fun](https://propad.fun) shows a streaming market pulse of the busiest Solana pairs alongside the project record board.

## Features

- Streaming market pulse: top ten Solana pairs by 24h volume, a ticker, stat tiles and sortable tabs.
- Click-to-copy address slot at the top of every page, inert until an address is stated.
- A record board in which every external fact is a single entry with a state of stated, absent or unconfirmed.
- Motion system with spring-based reveals, hero parallax, spotlight hover and a full reduced-motion fallback.
- Static output in `dist/`, ready to be dragged onto any static host.
